## 📌 Descripción del proyecto

Este proyecto consiste en el desarrollo de un dashboard interactivo en Power BI utilizando el dataset de **Northwind Traders**, enfocado en el análisis de ventas globales y desempeño comercial.

El objetivo principal fue transformar datos de ventas en información visual clara y útil para apoyar la toma de decisiones empresariales.

A través de este dashboard se pueden analizar indicadores clave de rendimiento (KPIs), productos más vendidos, ventas por país, comportamiento anual y tiempos de entrega.

---

## 🎯 Objetivos del dashboard

- Visualizar ventas totales  
- Analizar clientes y países activos  
- Identificar los productos más vendidos  
- Evaluar ventas por año  
- Revisar tiempos de entrega  
- Detectar oportunidades de mejora comercial  

---

## 📊 Indicadores principales (KPIs)

- 💰 Ventas Totales: $1.27 millones  
- 👥 Clientes: 91  
- 🌍 Países: 21  

---

## 📈 Visualizaciones incluidas

### Top 5 productos más vendidos

Permite identificar los productos con mayor volumen de ventas y su impacto en el negocio.

### Ventas por año

Muestra la evolución histórica de las ventas para detectar crecimiento, estabilidad o caídas.

### Ventas por país

Mapa geográfico que facilita el análisis de distribución comercial internacional.

### Tiempo de entrega

Comparación entre entregas a tiempo y retrasadas para evaluar eficiencia operativa.

### Segmentación por filtros

- Países  
- Categoría de producto  

Esto permite un análisis más dinámico e interactivo.

## 🧠 Conclusión

Este dashboard permite resumir información compleja de ventas en una visualización clara, rápida y estratégica.

Gracias al uso de Power BI, fue posible identificar patrones importantes en el comportamiento comercial, reconocer los productos con mejor rendimiento y analizar oportunidades de mejora en la logística de entrega.

También se observó que algunos productos concentran gran parte de las ventas, mientras que ciertos países representan mercados clave para la empresa.

Además, este proyecto fortaleció habilidades en Business Intelligence, visualización de datos y toma de decisiones basada en información.
